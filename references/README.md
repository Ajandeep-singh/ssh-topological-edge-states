# Literature review notes

The report includes four verified references spanning the original dimerized-chain work, random nearest-neighbor hopping, disordered SSH extensions, and a recent paper directly studying both on-site and hopping disorder. The latter makes clear that the broad disorder comparison is not itself a novelty claim. The student project should be presented as a reproducible computational study unless a narrower contribution is established by a deeper literature review.

The papers use different models and observables. In particular, long-range hopping changes the model symmetry and topology; transport and nonequilibrium studies do not directly establish results for this closed finite-chain calculation. The project's candidate-edge-state rule and gap proxy need their own validation.
